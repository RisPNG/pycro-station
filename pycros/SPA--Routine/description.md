Runs the complete SPA Routine v3.4.0 workflow without Excel or VBA.

Select the SPA input workbook and current PCO2161 and PCO2195 workbooks in XLSX, XLSM, or ODS format. Size List, Region & Destination, Developers, and Developers Location can optionally be selected in the same formats; packaged editable Excel defaults are used when they are omitted.
